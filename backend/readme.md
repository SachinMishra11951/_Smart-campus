# Smart Campus Management System

A Smart Campus Management System built using FastAPI, SQLite, HTML, CSS, and JavaScript.

## Features

- Student & Admin Login
- JWT Authentication
- Forgot Password with OTP Verification
- Complaint Management
- Resource Management
- Resource Booking
- Notifications
- Student Dashboard
- Admin Dashboard

## Tech Stack

### Backend
- FastAPI
- SQLAlchemy
- SQLite
- JWT Authentication

### Frontend
- HTML
- CSS
- JavaScript

## Backend Setup

1. Create a virtual environment

```bash
python -m venv .venv
```

2. Activate it

Windows:

```bash
.venv\Scripts\activate
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Start the backend

```bash
uvicorn main:app --reload
```

Backend runs at:

```
http://127.0.0.1:8000
```

## Frontend

Open the frontend using Live Server or any static web server.
